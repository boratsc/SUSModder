# Dokumentacja projektu SUSModder

Dokumentacja projektu znajduje się w [kolekcji SUSModder w Outline](https://outline.gradzik.org/collection/susmodder-jgFgaNSYmL). Pliki w `DOC/readme/` są używane przez główny `README.md` i pozostają w repozytorium.

Lokalne plany i materiały w `DOC/` mogą być nieaktualne; przed ich wykorzystaniem lub usunięciem porównaj je z Outline. Skrypty budowania i testowania są w `SKRYPTY/`.
