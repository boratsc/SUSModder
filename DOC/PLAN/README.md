# Aktywne plany

Po cleanupie Beta 1 katalog nie zawiera aktywnych planów funkcjonalnych.

Nowe plany można dodawać tutaj, ale tylko jeżeli nadal wymagają decyzji lub implementacji. Po zakończeniu przenieś je do `_archive/PLAN/<temat>/` albo `_archive/PLAN/completed/`.

Zakończone plany i kontrakty przeniesiono do:

- `_archive/PLAN/completed/`
- `_archive/PLAN/beta-1/`
- `_archive/PLAN/discord-oauth2/`
- `_archive/PLAN/stale-post-beta/`
