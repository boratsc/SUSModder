# Screenshoty do README

Pliki wrzucasz do tego folderu (`DOC/readme/`). README już ma podpięte ścieżki — wystarczy dodać pliki o tych nazwach.

## Wymagane pliki

| Plik | Co pokazać | Sugerowany kadr |
|------|------------|-----------------|
| `screenshot-main.png` | Główne okno aplikacji | Lista modów, motyw ciemny, widoczne kilka modów (np. Town of Us, The Other Roles), pasek wyszukiwania u góry |
| `screenshot-install.png` | Instalacja moda | Wybrany mod ze szczegółami — widoczny przycisk **Instaluj**, opis moda, wersja |
| `screenshot-launch.png` | Uruchomienie gry | Ten sam mod po instalacji — widoczny przycisk **Uruchom**, status „Zainstalowany” |

## Opcjonalnie (na później)

| Plik | Co pokazać |
|------|------------|
| `screenshot-lobby.png` | Tablica Lobby z menu |
| `screenshot-pink.png` | Główne okno w różowym motywie |

## Wskazówki

- Szerokość ~1200–1400 px wystarczy; README skaluje obrazki do 700 / 340 px.
- Ukryj wrażliwe dane (ścieżki dysku, nicki) jeśli są widoczne.
- `screenshot-install` i `screenshot-launch` mogą być kadrem tego samego moda przed i po instalacji — wtedy dobrze widać różnicę między **Instaluj** a **Uruchom**.

## Logo

`logo.png` jest już wygenerowane z `SUSModder/Assets/icon.ico`. Możesz je podmienić własną wersją 256×256 px.
