## Wskazówki

- Szerokość **1400 px** (domyślny rozmiar okna 3.0); README skaluje obrazki do 700 / 340 px.
- Ukryj wrażliwe dane (ścieżki dysku, nicki) jeśli są widoczne.
- `screenshot-install` i `screenshot-launch` mogą być kadrem tego samego moda przed i po instalacji.
- Test DPI: zrób dodatkowo wariant 125% tylko jeśli README wspomina skalowanie — nie jest wymagany w repo.
